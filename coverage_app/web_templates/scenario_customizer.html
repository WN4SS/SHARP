How to use

  1. Blue markers = real deployed antennas (read-only). Click one to inspect its parameters.
  2. Use the Marker draw tool () to drop a new virtual base station (red). A popup opens immediately.
  3. In the popup click Add New Antenna, then drag the mouse to aim the azimuth arrow, and the antenna is created. Edit its parameters (azimuth, frequency, power, gain) directly in the popup and click Save per antenna.
    • Use Move to drag the whole station to a new position.
    • Use Delete on individual antennas or on the station itself to remove them.
  4. CBRS channel panel (top of map): 15 tiles cover CH1–CH15 (3550–3690 MHz in 10 MHz steps). Green = available; Red = occupied. Click a red tile to see which antennas use that channel — the matching arrows flash orange and an aura pulse appears on the station.
  5.  Random BS Generator (dice toolbar button): opens a form to generate multiple virtual stations at once. Set the number of stations and antennas per station, the max scatter radius, and the Tx power / Tx gain ranges for random assignment.
  6. When ready, click the 💾 Save toolbar button to save the scenario and return to the terminal.
